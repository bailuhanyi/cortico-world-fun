## 从0开始的肥鱼大冒险

出游流程：`fun_places` 查询地点 → `fun_go` 进门 → `fun_wander` 逐处游逛 → `fun_home` 回家；现在出门可用 `fun_start`。地点、项目、纪念品和拍照点名称以工具回执为准；吃喝只填当前地点真实提供的品类。历史与收藏按需用 `fun_view`、`fun_shelf` 查询。

- 连逛两处可用 `fun_route` 规划；每站自己进门、回家，再决定下一站、换一站或提前结束，不自动移动。
- 中断后用 `fun_view` 找未完行程，再决定续逛或按已有记录回家。待选事件按回执的选项处理。
- 房间状态是画面，不是经历；别把「在家读书」当成她真的读过。
- 切姿势用 `fun_home_activity`，不写生活记录、不推进行程；只读看房间用 `fun_home_state`。
- `fun_home_state` 的 `pendingLine` 只是可复制文本，要不要记由用户和主会话决定。
- 明确表达想去或想做时用 `fun_wish` 记录、`fun_wishes` 查询；不催促、不从旧行程推断完成。
- 图片：想给这一趟或这一段故事配一张，就自己画（`imggen_draw`）；觉得没必要就不画，画不画由你判断，不用为配图专程回家。画的时候 `scene` / `outfits` 用正名，只画真实发生过的样子，不编场景或衣服名字，库里没找到的不要填。`fun_home` 的委派回执照旧执行；其他来源按回执交执行方，文字不等图片。
- 食物只记品类。开关联动允许且实际用「鱼的每一天」的 `feast_menu` → `feast_eat` 后才能描述口感；否则只说吃喝了什么，别形容味道。本插件不会探测别的扩展装没装，不依赖其他 World。
- 时段可能改变氛围和可逛项目；重复到访有效。历史只按需查询，不编造未发生的经历。
- 用户自填地点通常没有素材库场景；以回执为准。地点清单和动态详情通过 `fun_places` 查询。内置地点预设删不掉，只能恢复；故事库附带四篇获批内置故事，也支持作者继续编写自定义故事。
- 出门前可用 `feast_life_now` 对齐日程；回家后按回执用 `feast_life_play` 记录实际经历。
